# Cover Design

- title: 微软悄悄升级了RAG
- subtitle: 99%的人还不知道
- display_duration: 3
- style: 科技感暗色调，深蓝黑背景，霓虹蓝/红强调色，信息密度高
- layout: 标题居中，副标题下方，底部装饰性代码/图谱元素
- background: 深色渐变（#0a0e1a → #0d1b2a），叠加半透明知识图谱节点网络作为背景装饰
- key_elements:
  - 主标题"微软悄悄升级了RAG"（大字，白色，字重900）
  - 副标题"99%的人还不知道"（中字，霓虹蓝 #00d4ff，带轻微发光效果）
  - 背景：抽象知识图谱节点连线（低透明度，蓝色）
  - 左上角微软风格四色方块装饰（小尺寸，品牌暗示）
  - 底部横向分割线（渐变蓝色）
  - "RAG → GraphRAG" 小标签（右下角，技术感）
- animation: 主标题从模糊到清晰渐入（0.8s），副标题延迟0.3s后从下方滑入，背景图谱节点缓慢脉冲
